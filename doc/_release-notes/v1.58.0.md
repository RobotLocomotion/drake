# Announcements

<!-- <relnotes for announcements go here> -->

* Newer libc++ introduced a map and set lookup optimization that requires
  `std::less` specializations to be equivalent to `operator<`. Any other
  behavior is non-conforming. For more context on the change, see the discussion
  on the below LLVM issues [^1][^2]. SolverId and Formula simply need operator
  overloads. For Expression and Variable, their `operator<`s are used for
  logical comparison while their `std::less` specializations are used for
  structural comparison. (Ditto for `std::equal_to` vs. `operator==`.) Instead,
  we provide new comparators, and port Drake's containers to use them
  throughout. The old specializations are deprecated, but for compatibility
  during the deprecation period, the new comparators are still an alias to the
  old on platforms where they aren't strictly required (i.e., older libc++, or
  libstdc++) ([#25014][_#25014]).
* The minimum supported macOS is now Tahoe (26) ([#24988][_#24988]).

# Notes


This release provides
[pre-compiled binaries](https://github.com/RobotLocomotion/drake/releases/tag/v1.58.0).
See [Installation](/installation.html) for instructions on how to use them.

Drake binary releases incorporate a pre-compiled version of
[SNOPT](https://ccom.ucsd.edu/~optimizers/solvers/snopt/) as part of the
[Mathematical Program toolbox](/group__solvers.html). Thanks to
Philip E. Gill and Elizabeth Wong for their kind support.
