# Announcements

<!-- <relnotes for announcements go here> -->

* Drake's use of pybind11 is now deprecated. Drake's default will change to nanobind around 2026-12-01 ([#24897][_#24897])
* This release will be the last release that supports Sequoia (i.e., macOS 15),
  as documented on our [OS Support](/stable.html#os-support) page ([#24941][_#24941]).
  * We are working to add official support for macOS Golden Gate (27) soon.

# Breaking changes since v1.56.0

<!-- <relnotes for breaking-changes go here> -->

* `pydrake.common.trigger_an_assertion_failure` has been changed to internal use only ([#24910][_#24910])

Refer to our [Drake Stability Guidelines](/stable.html) for our policy
on API changes.

# Notes


This release provides
[pre-compiled binaries](https://github.com/RobotLocomotion/drake/releases/tag/v1.57.0).
See [Installation](/installation.html) for instructions on how to use them.

Drake binary releases incorporate a pre-compiled version of
[SNOPT](https://ccom.ucsd.edu/~optimizers/solvers/snopt/) as part of the
[Mathematical Program toolbox](/group__solvers.html). Thanks to
Philip E. Gill and Elizabeth Wong for their kind support.
